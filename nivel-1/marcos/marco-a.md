## No encontro (~90–120 min)
1. **Demo (5–7 min por pessoa):** projeto rodando, API via `curl`/HTTPie justificando os status codes, `git log` e a última tag.
2. **Exercícios (20–30 min):**
   - Mini-kata de TDD em dupla, com commit a cada passo red → green → refactor.
   - Classificação de comentários: remover ou manter, com justificativa.
   - Caça a smells em código desconhecido (20 min): ao menos 3 smells pelo nome e a refatoração que resolve cada um.
3. **Rodada de explicação:** 1–2 perguntas dos critérios de saída, respondidas com o próprio projeto.
4. **Retrospectiva (10 min):** criar a discussão em 🔁 Retrospectivas.
