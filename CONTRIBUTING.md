# Como contribuir com o programa

Este repositório é tratado como código: mudanças entram por PR, com review e versão.

## Fluxo

1. **Ideia ou problema:** abra em Discussions → 💡 Sugestões. Se for consenso (ou uma correção óbvia), vira issue com label `roadmap`.
2. **Fork e branch:** faça um fork do repositório e crie uma branch a partir de `main` com nome curto (`ajusta-semana-04`, `corrige-data-marco-a`).
3. **Commits atômicos** no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/):
   - `docs(nivel-1): detalha semana 3`
   - `fix(roadmap): corrige data do Marco A`
   - `feat(nivel-2): define cronograma do nível 2`
4. **PR** com descrição (o quê, por quê) referenciando a issue (`Closes #12`). Qualquer pessoa pode abrir PR e revisar, mas **só o mantenedor (@vinicimdohs) aprova e faz o merge na `main`**.
5. **Release:** quem administra cria a tag seguindo a regra de versão do [README](README.md#versionamento-deste-repositório).

## O que não entra aqui

- Código dos projetos (fica no repositório de cada participante).
- Dados, nomes ou informações internas de empresa.
- Respostas prontas dos exercícios de marco antes do marco acontecer.
